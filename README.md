# GCL Elements

Gulf Coast Local custom Breakdance elements.

Element Studio save location ("GCL Elements") holding copies of the core elements that the Breakdance MCP server hides from AI agents: Div, Text, Rich Text, Image, Text Link, Wrapper Link and Code Block.

Master copy lives on the GCL MCP Starter site (donaldj185.sg-host.com). Edit elements there in Element Studio, then publish from that site.

Note: GCL Code Block needs `ssr.php` (copied from the core Code Block); Element Studio does not create it.
